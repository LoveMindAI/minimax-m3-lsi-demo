These folders are copied from earlier synthetic demos so readers can compare MiniMax M3 against prior Gemma 4 31B and Opus 4.6 generations.

- `bud_name_projection_packet/`: synthetic name-projection demo using Bud Heffner, Cillian Frost, and Haruki Minamoto.
- `isolde_name_projection_packet/`: synthetic name-projection variant using Isolde Wren, Cillian Frost, and Haruki Minamoto.
- `megyn_synthetic_packet/`: earlier single-character synthetic profile and LSI packet.

These are all fictional/synthetic packets. They do not contain real PARSEL participant rows, real PIDs, raw participant profiles, or raw model-call logs.
